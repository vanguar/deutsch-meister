## Шаг 1. Google Search Console — самое важное (15 минут)

Без этого Google может месяцами не замечать сайт.

1. Открой https://search.google.com/search-console и войди своим Google-аккаунтом.
2. Нажми «Добавить ресурс» → справа выбери **«Ресурс с префиксом в URL»**
   (вариант «Домен» для github.io не подойдёт) → вставь
   `https://vanguar.github.io/german-morning/` → «Продолжить».
3. Способ подтверждения — **«HTML-тег»**. Google покажет строку вида
   `<meta name="google-site-verification" content="AbC123…">`.
   Скопируй **только код из content="…"** и пришли его мне (Claude) со словами
   «код Google для лендинга». Я впишу его в сайт и опубликую — это займёт пару минут.
4. После моего сообщения «опубликовано» вернись в Search Console и нажми **«Подтвердить»**.
5. В меню слева: **«Файлы Sitemap»** → в поле впиши `sitemap.xml` → «Отправить».
6. В меню слева: **«Проверка URL»** → по очереди вставь эти адреса и у каждого нажми
   **«Запросить индексирование»**:
   - `https://vanguar.github.io/german-morning/uk/`
   - `https://vanguar.github.io/german-morning/ru/`
   - `https://vanguar.github.io/german-morning/uk/news/`
   - `https://vanguar.github.io/german-morning/ru/news/`
7. По желанию: так же добавь второй ресурс `https://vanguar.github.io/deutsch-meister/`
   (само приложение). Код подтверждения для него тоже присылай мне.

Чего ждать: первые страницы появляются в Google через 3–14 дней, заметный трафик — через 1–3 месяца.
Раз в неделю заглядывай в раздел «Эффективность»: там видно, по каким запросам тебя находят.

## Шаг 2. Bing Webmaster Tools (5 минут, после шага 1)

Bing — это ещё и DuckDuckGo, Yahoo, поиск в ChatGPT и Copilot.

1. Открой https://www.bing.com/webmasters и войди (подойдёт Google-аккаунт).
2. Выбери **«Импорт из Google Search Console»** и разреши доступ — сайт и sitemap перенесутся сами,

3. Если импорт не подходит: «Добавить сайт» вручную → способ «HTML Meta Tag» →

## Шаг 3. Обновить профиль бота (2 минуты)

Новые описания бота уже лежат в `scripts/set_bot_description.py`: ключевые слова
(«безкоштовний курс німецької A1–B2», «68 уроків», «новини з перекладом») и ссылка на сайт.
Применить их можно только твоим токеном бота:

1. В Telegram открой @BotFather → `/mybots` → German Morning → **API Token** → скопируй токен.
2. В Claude Code (в этой папке проекта) отправь сообщение, заменив `ТОКЕН` своим токеном:
   ```
   ! BOT_TOKEN=ТОКЕН python scripts/set_bot_description.py
   ```
   Если появится ошибка про `BOT_TOKEN=…`, значит, команда выполняется в PowerShell — тогда так:
   ```
   ! $env:BOT_TOKEN="ТОКЕН"; python scripts/set_bot_description.py
   ```
   Должно появиться `OK: default` и `OK: ru`.
3. Проверь: открой профиль бота в Telegram — в описании должна быть ссылка на сайт.

Токен никому не пересылай и не сохраняй в файлах проекта (репозиторий публичный).

## Шаг 4. Сделать бота «приложением» в Telegram — Main Mini App (10 минут)

Тогда в профиле бота появится большая кнопка **«Открыть»**, скриншоты и видео,
а бот сможет попадать в поиск по приложениям и в витрину Mini Apps внутри Telegram.

1. @BotFather → `/mybots` → German Morning → **Bot Settings** → **Configure Mini App**
   → **Enable Mini App**.
2. Ссылка на приложение: `https://vanguar.github.io/deutsch-meister/`
3. Там же добавь **превью (Preview media)**: 3–5 вертикальных скриншотов с телефона —
   список уроков, урок со словами, диктант, книга с подсказками, новость.
   Можно для украинского и русского языков отдельно.
   Если хочешь, попроси меня — я сделаю готовые скриншоты.
4. Проверь в **Bot Settings → Menu Button**, что кнопка меню открывает то же приложение.

## Шаг 6. Свой Telegram-канал с новостями (постоянно, лучший способ роста)

Каналы находятся через поиск Telegram, а их публичная веб-версия (`t.me/s/имя_канала`)
индексируется Google.

1. Создай публичный канал, например `@GermanMorningNews` или `@nimetska_shchodnia`
   (название с ключевыми словами: «Німецька щодня — German Morning»).
2. Добавь @GermanMorningBot в администраторы канала.
3. Публикуй каждую новую статью: немецкий заголовок, 2–3 предложения с переводом, фото и две ссылки:
   - «Читати з підказками в боті» → `https://t.me/GermanMorningBot?start=channel`
   - «Повний текст з перекладом» → ссылка на статью на сайте (`…/uk/news/<статья>/`)
4. Когда канал заведёшь, скажи мне — я могу сделать так, чтобы бот сам публиковал туда
   каждую новую статью.

Правила, чтобы не забанили: сначала прочитай правила чата, пиши от себя и по делу,
одно сообщение в одну группу, без повторов. Для каждого места делай свою метку,
чтобы в `/stats` было видно, что сработало:
`https://t.me/GermanMorningBot?start=fb_berlin`, `…?start=reddit`, `…?start=chat_munich`
(латиница, цифры, `_` и `-`, до 64 символов).

## Регулярно (почти без твоего участия)

- **Новые новости.** Когда просишь меня добавить статьи, я теперь сразу пересобираю и сайт:
  статьи появляются на `…/uk/news/` и `…/ru/news/`, обновляется sitemap,
  и адреса отправляются в IndexNow. Можно просто написать: «добавь новости и обнови сайт».
- Свежие статьи 2–3 раза в неделю — главный сигнал для поисковиков, что сайт живой.

## По желанию

- **Свой домен** (например `germanmorning.app`, около 10–20 € в год): лучше запоминается,
  вызывает больше доверия. Купи домен — я настрою его на GitHub Pages и перенесу всё без потери индексации.
- **Короткие видео** (TikTok / YouTube Shorts / Reels): «немецкое слово дня», «ошибка дня»
  со ссылкой на бота в профиле — хорошо работает для языковых проектов.
- **Отзывы.** Попроси первых пользователей оставить отзыв в каталогах (TGStat и т. п.) —
  это поднимает бота в подборках.

## Чего не делать

- Не покупать накрутку подписчиков и пользователей: Telegram и каталоги это видят, бот теряет позиции.
- Не рассылать одно и то же сообщение по десяткам чатов: бан и жалобы на бота.
- Не публиковать токен бота нигде (ни в чатах, ни в файлах проекта).
