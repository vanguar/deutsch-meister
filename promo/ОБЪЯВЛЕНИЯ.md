## 2. Площадки

Отмечай `[ ]` → `[x]`. Правила проверены 22.11.2026 — перед публикацией перечитай.

### Можно сразу (каталоги, самопродвижение разрешено)

| | Где | Как | Метка |
|---|---|---|---|
| [ ] | **Telegram Apps Center** (tApps) — главный каталог Mini Apps | заявка через бота @app_moderation_bot; нужно включённое Main Mini App (`Продвижение.md`, шаг 4) | `tapps` |
| [ ] | **TGStat** | https://tgstat.ru/add-bot, категория «Образование» | `tgstat` |
| [ ] | **AlternativeTo** — там уже есть Telegram-боты для немецкого (KeelAI, Learn Languages AI) | «Add application», категория Language Learning; потом предложить как альтернативу Duolingo / GermanPod101 | `alternativeto` |
| [ ] | **Product Hunt** | запуск продукта; лучше во вторник–четверг, текст 1.4 | `producthunt` |

### Можно по правилам сообщества

| | Где | Условие | Текст |
|---|---|---|---|
| [ ] | **r/languagelearning** | только в закреплённом треде «Share your resources» (по средам, раз в две недели); обязательно указать, что ты разработчик. Отдельные посты о своём продукте запрещены | 1.4 |
| [ ] | Telegram-чаты «Українці в Берліні / Мюнхені / Гамбурзі…», чаты интеграционных курсов | сначала правила чата; если реклама запрещена — написать админу и попросить разрешения | 1.1 / 1.2 |
| [ ] | Facebook-группы «Українці в Німеччині», группы по изучению немецкого | то же: правила → вопрос админу → одно сообщение | 1.1 / 1.3 |
| [ ] | Учителя немецкого, языковые школы, кураторы интеграционных курсов (VHS) | личное письмо, а не рассылка | 1.5 |

### Нельзя

- **r/German** — реклама и самопродвижение запрещены полностью, в любой форме.
- Одинаковое сообщение в десятки чатов подряд, накрутка, рассылка в личку незнакомым людям.
