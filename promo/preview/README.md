# Превью для профиля бота @GermanMorningBot

Скриншоты приложения для блока превью (Main Mini App) в профиле бота:
1170×2532, вертикальные, как экран iPhone. Два комплекта по 8 кадров:

- `uk/` — украинский интерфейс (основной: его увидят все, у кого Telegram не на русском);
- `ru/` — русский интерфейс (для тех, у кого Telegram на русском).

| № | Файл | Что на экране |
|---|---|---|
| 1 | `01-course.jpg` | Карта курса: уроки уровня A1 |
| 2 | `02-phrases.jpg` | Урок: ключевые фразы с озвучкой и переводом |
| 3 | `03-words.jpg` | Словарь урока: артикли, транскрипция, перевод |
| 4 | `04-dictation.jpg` | Упражнения: диктант и флешкарты |
| 5 | `05-book-interlinear.jpg` | Книга с подстрочным переводом |
| 6 | `06-word-tip.jpg` | Подсказка к слову в книге |
| 7 | `07-news.jpg` | Новости на немецком по рубрикам |
| 8 | `08-article.jpg` | Статья с фото |

## Как скачать на телефон

Открой на телефоне папку на GitHub и сохрани нужные картинки
(открыть файл → «⋯» / «Download» → сохранить в галерею):

- украинские: https://github.com/vanguar/deutsch-meister/tree/main/promo/preview/uk
- русские: https://github.com/vanguar/deutsch-meister/tree/main/promo/preview/ru

## Как загрузить

См. `Продвижение.md`, шаг 4.3. Коротко: сначала включить Main Mini App в @BotFather,
потом открыть профиль бота на телефоне → пункт превью → загрузить кадры по порядку
(украинский комплект — основной, русский — для русского языка Telegram).

## Пересъёмка

После изменений в приложении (из корня репо):

```sh
python -m http.server 8765
node --experimental-websocket tools/promo_shots.mjs   # PNG в promo/preview/<uk|ru>/
```

Скрипт сохраняет PNG; для этой папки их конвертировали в JPEG (quality 92).
