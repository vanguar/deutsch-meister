# Deutsch Meister — правила для генерации контента

Касается всех уроков, карточек, заметок (`note`), подсказок, глоссариев,
новостей, книг, переводов (`i18n/uk`), текстов бота и генераторов
(`gen_lessons.py`, `tools/news/*.py`).

## Аудитория: русский язык интерфейса ≠ Россия

The UI/explanation language may be Russian, but never infer that the user is
from Russia. The target user is Ukrainian. Use Ukrainian context when
country-specific comparison is genuinely useful; otherwise use geographically
neutral wording.

- Не писать «у нас в РФ», «у нас в России», «в нашей стране» (в значении
  России), «по российским меркам», «российская нумерация/школы/адреса» и т.п.
- Сравнение с родной реалией нужно → с Украиной: «2-й этаж по украинской
  нумерации». Не нужно → нейтрально: «der erste Stock — этаж над Erdgeschoss».
- Валюта в примерах — евро (или гривна, если нужна страна пользователя);
  не рубли. Телефоны, адреса, города по умолчанию — немецкие или украинские.
- Флаг 🇷🇺 не использовать как значок русского языка/перевода (🌐, «RU»).
- «В русском языке», «по-русски», «русский перевод» — допустимо: это язык.
- Россия как предмет материала (например, российский космонавт в новости) —
  допустима.

Проверка: `python scripts/test_audience_wording.py` (`make check-audience`,
гоняется в GitHub Actions). Если Россия — законный предмет материала и тест
ругается, добавить точечное исключение в `ALLOW`.
